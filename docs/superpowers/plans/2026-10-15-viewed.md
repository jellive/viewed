# viewed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** push 된 GitHub 브랜치를 PR 전에 파일별로 viewed 체크하고, diff 가 바뀐 파일만 다시 unread 로 돌리는 앱(맥 Electron + 폰 PWA)을 만든다.

**Architecture:** `packages/core`(UI 없는 TS)가 GitHub 호출·diff 지문·판정·gist 동기화를 맡는다. `apps/web`(React + Vite)가 같은 빌드를 PWA 와 Electron(`apps/desktop`)에 내준다. 서버는 없다 — 브라우저/앱이 `api.github.com` 을 직접 부른다.

**Tech Stack:** pnpm 11 workspace · TypeScript · Vitest 5.0.4 · React 19.3.1 · Vite 8.3.4 · @vitejs/plugin-react 6.1.2 · vite-plugin-pwa 2.0.0 · diff(jsdiff) 9.0.0 · Electron 44.7.2 · @playwright/test

**Spec:** `docs/superpowers/specs/2026-10-15-viewed-design.md`

## Global Constraints

- **공개 레포다.** 커밋에 절대경로(`/Users/...`), 토큰, 회사 org·계정 이름을 넣지 않는다. 테스트 픽스처의 owner/repo 는 `acme/widget` 같은 가짜 이름만.
- 서버 없음. 네트워크는 `https://api.github.com` 과 gist `raw_url`(`gist.githubusercontent.com`) 뿐.
- 판정은 diff 지문(spec §5.2)으로만. 지문이 같으면 viewed, 다르면 unread — 다른 규칙을 추가하지 않는다.
- compare 파일 수가 300 이면 `incomplete: true`, 그때 `complete` 는 항상 `false`.
- gist 는 기기별 파일 `device-<deviceId>.json` — 기기는 자기 파일만 쓴다.
- 기록 키는 HMAC-SHA256(공유 비밀, `owner/repo|branch|path`) hex. 이름 원문을 gist 에 쓰지 않는다.
- 토큰은 gist 에 넣지 않는다. Electron 은 safeStorage 비동기 API, PWA 는 localStorage.
- 오류 상태(목록 불완전·diff 조회 실패·이후 변경 조회 불가·동기화 실패·토큰 문제)를 viewed/완료로 표시하지 않는다.
- Node 26, pnpm 11.14 (이 머신 실측).

## Review Focus

1. **force-push 로 옛 blob 이 사라짐** — "본 이후 변경" 요청이 404 → 화면이 깨지지 않고 "이후 변경 조회 불가 + 전체 diff". 테스트: Task 3 `blobText` 404 → null, Task 8 E2E.
2. **gist 파일이 1MB 를 넘어 `truncated: true`** — 기록이 잘린 JSON 으로 파싱돼 전부 unread 가 되는 대신 `raw_url` 로 전체를 받는다. 테스트: Task 5.
3. **base 쪽만 바뀐 경우(main 을 브랜치에 merge)** — head blob 은 같아도 patch 가 바뀌면 unread. 테스트: Task 2 지문.
4. **기기 시계가 어긋난 두 기록** — 같은 키에 두 기기 기록이 있으면 `at` 이 늦은 쪽. 같은 `at` 이면 `viewed:false` 가 이긴다(보수적). 테스트: Task 5.
5. **patch 없는 파일(바이너리·대용량)** — 본문 없이 체크만 가능, 지문은 blob sha. 테스트: Task 2·Task 7 E2E.

```bash
# 공개 레포에 들어가면 안 되는 문자열을 추적 파일 전체(바이너리 포함)에서 찾는다.
set -euo pipefail
# 문자열을 쪼개 둔다 — 이 코드를 인용한 문서(계획서 등)가 스캔에 걸리지 않게
pattern="/Use""rs/[a-z]|ghp_[A-Za-z0-9]{36}|github_pat_[A-Za-z0-9_]{20,}"
# 회사 이름 같은 비공개 패턴은 레포에 적지 않는다 — 추적 안 되는 .prepublish-extra(한 줄에 정규식 하나)에서 읽는다
if [ "${1:-}" = "--history" ]; then
  # push 할 히스토리 전체(지워진 줄 포함). rg: 0=발견 1=없음 2=오류 — 오류를 '없음'으로 읽지 않는다.
  set +e; git log --all -p | rg -a -n -e "$pattern"; rc=$?; set -e
  [ "$rc" -eq 1 ] && { echo "history scan ok"; exit 0; }
  [ "$rc" -eq 0 ] && { echo "히스토리에 공개 금지 패턴"; exit 1; }
  echo "scan error rc=$rc"; exit 2
fi
hits=$(git ls-files -z | xargs -0 rg -a -l -e "$pattern" -- 2>/dev/null || true)
if [ -n "$hits" ]; then
  echo "공개 금지 패턴 발견:"; echo "$hits"; exit 1
fi
echo "scan ok"
```

```ts
describe('fingerprint', () => {

    const a = await fingerprint(base);
    expect(a).toMatch(/^[0-9a-f]{64}$/);
    expect(await fingerprint({ ...base })).toBe(a);
```

```ts
import type { ChangedFile } from './types';

export async function sha256Hex(text: string): Promise<string> {
  const buf = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(text));
  return [...new Uint8Array(buf)].map((b) => b.toString(16).padStart(2, '0')).join('');
}

// spec §5.2: patch 가 있으면 patch, 없으면 blob sha. 상태·이전 경로·모드를 같이 넣는다.
export function fingerprint(file: ChangedFile): Promise<string> {
  const body = file.patch !== undefined ? `patch:${file.patch}` : `blob:${file.blobSha ?? ''}`;
  return sha256Hex(JSON.stringify([file.status, file.previousPath ?? '', file.mode ?? '', body]));
}
```

`packages/core/src/github.ts`
```ts
import type { ChangedFile, FileStatus } from './types';

export type FetchLike = (url: string, init?: RequestInit) => Promise<Response>;

export class GitHubError extends Error {
  constructor(public status: number, message: string) { super(message); }
}

export class GitHub {
  constructor(
    private token: string,
    private fetchImpl: FetchLike = (u, i) => fetch(u, i),
    private apiBase = 'https://api.github.com',
  ) {}

  private async req(path: string, init: RequestInit = {}, accept = 'application/vnd.github+json'): Promise<Response> {
    const res = await this.fetchImpl(this.apiBase + path, {
      ...init,
      headers: {
        authorization: `Bearer ${this.token}`,
        accept,
        'x-github-api-version': '2022-11-28',
        ...(init.body ? { 'content-type': 'application/json' } : {}),
      },
    });
    if (!res.ok) throw new GitHubError(res.status, `${res.status} ${path}`);
    return res;
  }

  private async json<T>(path: string, init?: RequestInit): Promise<T> {
    return (await this.req(path, init)).json() as Promise<T>;
  }

  async branchHead(owner: string, repo: string, branch: string): Promise<string> {
    const b = await this.json<{ commit: { sha: string } }>(`/repos/${owner}/${repo}/branches/${encodeURIComponent(branch)}`);
    return b.commit.sha;
  }

  async defaultBranch(owner: string, repo: string): Promise<string> {
    return (await this.json<{ default_branch: string }>(`/repos/${owner}/${repo}`)).default_branch;
  }

  async compare(owner: string, repo: string, base: string, headSha: string) {
    type F = { filename: string; previous_filename?: string; status: FileStatus; sha: string; patch?: string };
    const body = await this.json<{ files?: F[] }>(`/repos/${owner}/${repo}/compare/${encodeURIComponent(base)}...${headSha}`);
    const raw = body.files ?? [];
    const files: ChangedFile[] = raw.map((x) => ({
      path: x.filename,
      previousPath: x.previous_filename,
      status: x.status,
      blobSha: x.status === 'removed' ? null : x.sha,
      ...(x.patch !== undefined ? { patch: x.patch } : {}),
    }));
    // GitHub 은 300개에서 자르고, 정확히 300개와 잘림을 구분할 수 없다 (spec §5.1)
    return { files, truncated: raw.length >= 300 };
  }

  async treeModes(owner: string, repo: string, headSha: string) {
    const t = await this.json<{ truncated: boolean; tree: { path: string; mode: string; type: string }[] }>(
      `/repos/${owner}/${repo}/git/trees/${headSha}?recursive=1`);
    const modes = new Map<string, string>();
    for (const e of t.tree) if (e.type === 'blob' || e.type === 'commit') modes.set(e.path, e.mode);
    return { modes, truncated: t.truncated };
  }

  async blobText(owner: string, repo: string, sha: string): Promise<string | null> {
    try {
      return await (await this.req(`/repos/${owner}/${repo}/git/blobs/${sha}`, {}, 'application/vnd.github.raw+json')).text();
    } catch (e) {
      if (e instanceof GitHubError && e.status === 404) return null;
      throw e;
    }
  }

  getGist(id: string) {
    return this.json<{ files: Record<string, { content: string; truncated: boolean; raw_url: string }> }>(`/gists/${id}`);
  }

  async updateGistFile(id: string, name: string, content: string): Promise<void> {
    await this.req(`/gists/${id}`, { method: 'PATCH', body: JSON.stringify({ files: { [name]: { content } } }) });
  }

  async fetchRaw(url: string): Promise<string> {
    const res = await this.fetchImpl(url);
    if (!res.ok) throw new GitHubError(res.status, `${res.status} raw`);
    return res.text();
  }
}
```

```ts
export async function recordKey(secret: string, owner: string, repo: string, branch: string, path: string): Promise<string> {
  const enc = new TextEncoder();
  const key = await crypto.subtle.importKey('raw', enc.encode(secret), { name: 'HMAC', hash: 'SHA-256' }, false, ['sign']);
  const sig = await crypto.subtle.sign('HMAC', key, enc.encode(`${owner}/${repo}|${branch}|${path}`));
  return [...new Uint8Array(sig)].map((b) => b.toString(16).padStart(2, '0')).join('');
}
```

```ts
import { fingerprint } from './fingerprint';
import { recordKey } from './keys';
import type { DeviceState, Review, ReviewItem, Snapshot, ViewRecord } from './types';

export async function buildReview(snap: Snapshot, state: DeviceState, secret: string): Promise<Review> {
  const items: ReviewItem[] = [];
  for (const file of snap.files) {
    const key = await recordKey(secret, snap.owner, snap.repo, snap.branch, file.path);
    const fp = await fingerprint(file);
    const record = state[key];
    const state_ = !record || !record.viewed ? 'unread' : record.fp === fp ? 'viewed' : 'changed-since-viewed';
    items.push({ file, key, fp, state: state_, record });
  }
  const viewedCount = items.filter((i) => i.state === 'viewed').length;
  return { items, viewedCount, total: items.length, incomplete: snap.truncated,
    complete: !snap.truncated && items.length > 0 && viewedCount === items.length };
}

export function markRecord(item: ReviewItem, headSha: string, viewed: boolean, now = new Date()): ViewRecord {
  return { fp: item.fp, blob: item.file.blobSha, head: headSha, at: now.toISOString(), viewed };
}
```

```ts
import type { GitHub } from './github';
import type { DeviceState, ViewRecord } from './types';

const PREFIX = 'device-';
export const deviceFileName = (deviceId: string) => `${PREFIX}${deviceId}.json`;

function newer(a: ViewRecord, b: ViewRecord): ViewRecord {
  if (a.at !== b.at) return a.at > b.at ? a : b;
  return a.viewed ? b : a;   // 같은 시각이면 해제 기록이 이긴다 (보수적)
}

export function mergeStates(states: DeviceState[]): DeviceState {
  const out: DeviceState = {};
  for (const s of states) for (const [k, v] of Object.entries(s)) out[k] = out[k] ? newer(out[k], v) : v;
  return out;
}

export async function loadAll(gh: GitHub, gistId: string, deviceId: string) {
  const gist = await gh.getGist(gistId);
  const states: DeviceState[] = [];
  let own: DeviceState = {};
  for (const [name, file] of Object.entries(gist.files)) {
    if (!name.startsWith(PREFIX) || !name.endsWith('.json')) continue;
    const text = file.truncated ? await gh.fetchRaw(file.raw_url) : file.content;
    const state = JSON.parse(text) as DeviceState;   // 깨진 파일은 던진다 — 조용히 빈 기록으로 바꾸지 않는다
    states.push(state);
    if (name === deviceFileName(deviceId)) own = state;
  }
  return { merged: mergeStates(states), own };
}

export function saveOwn(gh: GitHub, gistId: string, deviceId: string, own: DeviceState): Promise<void> {
  return gh.updateGistFile(gistId, deviceFileName(deviceId), JSON.stringify(own));
}
```

```ts
export interface AccountCfg { label: string; token: string }
export interface Settings { accounts: AccountCfg[]; gistAccount: string; gistId: string; secret: string; deviceId: string }

declare global {
  interface Window { viewedDesktop?: { getSecret(name: string): Promise<string | null>; setSecret(name: string, value: string): Promise<void> } }
}

const KEY = 'viewed.settings';

// Electron 이면 토큰·공유 비밀은 keychain(safeStorage) 쪽에 두고, localStorage 에는 빈 값만 남긴다
export async function loadSettings(): Promise<Settings | null> {
  const raw = localStorage.getItem(KEY);
  if (!raw) return null;
  const s = JSON.parse(raw) as Settings;
  const d = window.viewedDesktop;
  if (!d) return s;
  const accounts = await Promise.all(s.accounts.map(async (a) => ({ ...a, token: (await d.getSecret(`token:${a.label}`)) ?? '' })));
  return { ...s, accounts, secret: (await d.getSecret('secret')) ?? '' };
}

export async function saveSettings(s: Settings): Promise<void> {
  const d = window.viewedDesktop;
  if (!d) { localStorage.setItem(KEY, JSON.stringify(s)); return; }
  for (const a of s.accounts) await d.setSecret(`token:${a.label}`, a.token);
  await d.setSecret('secret', s.secret);
  localStorage.setItem(KEY, JSON.stringify({ ...s, secret: '', accounts: s.accounts.map((a) => ({ ...a, token: '' })) }));
}
```

```ts
import { useCallback, useEffect, useRef, useState } from 'react';
import { buildReview, markRecord, saveOwn, type DeviceState, type GitHub, type Review, type ReviewItem, type Snapshot } from '@viewed/core';

export type SyncStatus = 'idle' | 'pending' | 'error';

// 저장 못 한 기록을 기기에 남겨 둔다 — 실패 후 앱을 닫아도 체크가 사라지지 않게
const pendingKey = (deviceId: string) => `viewed.pending.${deviceId}`;
export function readPending(deviceId: string): DeviceState {
  try { return JSON.parse(localStorage.getItem(pendingKey(deviceId)) ?? '{}'); } catch { return {}; }
}

export function useReview(a: { snap: Snapshot; merged: DeviceState; own: DeviceState; secret: string; gh: GitHub; gistId: string; deviceId: string }) {
  // a.own 에는 open() 이 readPending 을 이미 합쳐 넣었다
  const [merged, setMerged] = useState(a.merged);
  const own = useRef<DeviceState>({ ...a.own });   // 비동기 저장이 읽으므로 호출 시점에 동기 갱신
  const version = useRef(0);                        // 마지막 변경 번호
  const chain = useRef<Promise<void>>(Promise.resolve());   // 저장은 한 번에 하나씩
  const [review, setReview] = useState<Review | null>(null);
  const [sync, setSync] = useState<SyncStatus>(Object.keys(readPending(a.deviceId)).length ? 'pending' : 'idle');
  const timer = useRef<ReturnType<typeof setTimeout> | null>(null);

  useEffect(() => { buildReview(a.snap, merged, a.secret).then(setReview); }, [a.snap, merged, a.secret]);

  const flush = useCallback(() => {
    if (timer.current) { clearTimeout(timer.current); timer.current = null; }
    const v = version.current;
    const body = own.current;
    // 앞 저장이 끝난 뒤에 보낸다 — 늦게 도착한 옛 PATCH 가 새 기록을 덮지 못하게
    chain.current = chain.current.then(async () => {
      try {
        await saveOwn(a.gh, a.gistId, a.deviceId, body);
        if (v === version.current) { localStorage.removeItem(pendingKey(a.deviceId)); setSync('idle'); }
      } catch { setSync('error'); }
    });
    return chain.current;
  }, [a.gh, a.gistId, a.deviceId]);

  const toggle = useCallback((item: ReviewItem, viewed: boolean) => {
    const rec = markRecord(item, a.snap.headSha, viewed);
    own.current = { ...own.current, [item.key]: rec };
    version.current += 1;
    localStorage.setItem(pendingKey(a.deviceId), JSON.stringify(own.current));
    setMerged((m) => ({ ...m, [item.key]: rec }));
    setSync('pending');
    if (timer.current) clearTimeout(timer.current);
    timer.current = setTimeout(flush, 1500);           // spec §6: 1.5초 모아서
  }, [a.snap.headSha, a.deviceId, flush]);

  useEffect(() => {                                     // 열 때 남아 있던 미저장 기록을 다시 보낸다
    if (Object.keys(readPending(a.deviceId)).length) void flush();
  }, [a.deviceId, flush]);

  useEffect(() => {                                     // spec §6: 화면을 떠날 때 즉시
    const onHide = () => { if (document.visibilityState === 'hidden' && timer.current) void flush(); };
    document.addEventListener('visibilitychange', onHide);
    return () => document.removeEventListener('visibilitychange', onHide);
  }, [flush]);

  return { review, toggle, sync, flush };
}
```

```tsx
import { useEffect, useState } from 'react';
import { structuredPatch } from 'diff';
import type { GitHub, ReviewItem } from '@viewed/core';
import { DiffView } from './DiffView';

type S = { kind: 'loading' } | { kind: 'ok'; lines: string[] } | { kind: 'unavailable' } | { kind: 'error'; msg: string };

export function SinceViewed({ gh, owner, repo, item }: { gh: GitHub; owner: string; repo: string; item: ReviewItem }) {
  const [tab, setTab] = useState<'since' | 'full'>('since');
  const [s, setS] = useState<S>({ kind: 'loading' });
  useEffect(() => {
    const oldSha = item.record?.blob, newSha = item.file.blobSha;
    if (!oldSha || !newSha) { setS({ kind: 'unavailable' }); return; }
    Promise.all([gh.blobText(owner, repo, oldSha), gh.blobText(owner, repo, newSha)])
      .then(([a, b]) => {
        if (a === null || b === null) return setS({ kind: 'unavailable' });
        const p = structuredPatch(item.file.path, item.file.path, a, b, 'viewed', 'now');
        setS({ kind: 'ok', lines: p.hunks.flatMap((h) => [`@@ -${h.oldStart},${h.oldLines} +${h.newStart},${h.newLines} @@`, ...h.lines]) });
      })
      .catch((e) => setS({ kind: 'error', msg: String(e) }));
  }, [gh, owner, repo, item]);

  if (s.kind === 'unavailable')
    return <div><p data-testid="since-unavailable">The version you viewed is no longer on GitHub (force-push?). Showing the full diff.</p><DiffView patch={item.file.patch} /></div>;
  if (s.kind === 'error') return <div><p data-testid="since-error" role="alert">{s.msg}</p><DiffView patch={item.file.patch} /></div>;
  return (
    <div>
      <button data-testid="since-tab" onClick={() => setTab('since')}>since viewed</button>
      <button data-testid="full-tab" onClick={() => setTab('full')}>full diff</button>
      {tab === 'full' ? <DiffView patch={item.file.patch} />
        : s.kind === 'loading' ? <p>loading…</p>
        : <pre data-testid="since-diff">{s.lines.join('\n')}</pre>}
    </div>
  );
}
```

```js
const { app, BrowserWindow, ipcMain, safeStorage } = require('electron');
const fs = require('node:fs/promises');
const path = require('node:path');

const ud = process.argv.find((a) => a.startsWith('--user-data-dir='));
if (ud) app.setPath('userData', ud.split('=')[1]);

const secretsFile = () => path.join(app.getPath('userData'), 'secrets.json');
async function readAll() {
  try { return JSON.parse(await fs.readFile(secretsFile(), 'utf8')); } catch { return {}; }
}
async function decrypt(b64) {
  const out = await safeStorage.decryptStringAsync(Buffer.from(b64, 'base64'));
  return typeof out === 'string' ? out : out.result;   // Step 1 에서 확인한 반환형에 맞춘다
}

ipcMain.handle('secret:get', async (_e, name) => {
  const all = await readAll();
  if (!all[name]) return null;
  try { return await decrypt(all[name]); } catch { return null; }   // 복호화 실패 = 재입력 (spec §7)
});
ipcMain.handle('secret:set', async (_e, name, value) => {
  const all = await readAll();
  all[name] = (await safeStorage.encryptStringAsync(value)).toString('base64');
  await fs.writeFile(secretsFile(), JSON.stringify(all), { mode: 0o600 });
});

    width: 1200, height: 900, title: 'viewed',
```
